# Expense Dashboard

Two static pages for the private `Expense-tracker` repo. No data lives here.

- `index.html` is the **Summary**: month switcher, where the money went (tap to drill into subcategories and payments), trend, how you paid, and payments that need a quick look.
- `add.html` is **Add**: paste an SMS or type `122 Snabbit maid`.

On first open it asks for the data repo and a fine-grained token with Contents: Read and write. The token stays in your browser.
